Mengelola dan menghapus data

Digital Qur’an tidak memerlukan akun. Tidak ada akun Digital Qur’an yang perlu ditutup atau dihapus.

Data di perangkat

  • Hapus penanda ayat dan kelola audio unduhan melalui fitur aplikasi.
  • Cabut izin lokasi atau notifikasi lewat Pengaturan Android → Aplikasi → Digital Qur’an → Izin/Notifikasi. Nama menu bisa berbeda antarperangkat.
  • Untuk menghapus seluruh data aplikasi pada perangkat, buka Pengaturan Android → Aplikasi → Digital Qur’an → Penyimpanan → Hapus data. Tindakan ini menghapus pengaturan, penanda, posisi baca, progres, dan data lokal aplikasi. Pastikan kamu memang ingin menghapusnya.
  • Mencopot aplikasi juga menghapus data lokal. Salinan yang sudah dibagikan ke aplikasi lain harus dikelola melalui aplikasi penerima tersebut.

Cadangan Android

Android dapat mencadangkan atau mentransfer preferensi sesuai pengaturan perangkat. Menghapus data lokal tidak otomatis menghapus salinan cadangan yang dikelola Android. Kelola cadangan lewat pengaturan akun dan perangkatmu.

Permintaan dan log layanan

Permintaan konten ke API dan layanan pihak ketiga dapat membawa parameter pencarian, wilayah, serta informasi jaringan. Menghapus aplikasi tidak otomatis menghapus log di penyedia layanan. Aplikasi tidak menyediakan tombol penghapusan log server.

Untuk pertanyaan atau permintaan terkait data, hubungi support@irengcloud.com. Jelaskan layanan dan perkiraan waktu penggunaan yang dimaksud tanpa mengirim data sensitif yang tidak diperlukan. Ketersediaan data dan penanganannya perlu dinilai bersama pengelola layanan terkait; halaman ini tidak menjanjikan penghapusan otomatis dari seluruh penyedia.
